# COMP 376 - Introduction to Game Development

Project description: Small game prototype made in Unity (C#) to test a design hypothesis. Build to be played in a web browser.

## Design Hypothesis: 
Does the player will intentionally allow a gnome to eat some mushrooms in order to benefit from the fertilizer it produces?
